# 小满

本地优先的手机记账本。数据只存在手机里，只有检查更新时会联网。

## 现在有什么

- **记账**：支出 / 收入 / 转账，自绘数字键盘，一级分类必选、二级可选，账户、日期、备注，逐笔「计入预算」开关
- **心情与状态**：每笔账可标「满意 / 后悔」和当时的状态（工作 / 加班 / 休息 / 通勤 / 出差 / 假期），列表和详情都会显示
- **流水**：按月切换、按日分组、顶部二级分类菜单一键筛选；点开详情可编辑；左滑删除，3 秒内可撤销
- **搜索筛选**：关键字（备注/商户）、收支类型、分类、账户、时间范围、金额区间
- **资产**：账户增改、类型（银行卡/电子钱包/现金/定期/活期）、余额（填实际值反推期初）、负债标记、账户备注、净资产 = 资产 − 负债；删除可撤销
- **导入**：CSV 自研解析，自动识别 UTF-8 / UTF-8 BOM / UTF-16 / GBK / GB18030；指纹去重；整批可撤销
- **导出与备份**：流水 CSV、全量备份 JSON，**可从备份恢复**（恢复前自动再备份一份）
- **统计**：月/年切换，环形图、分类榜、近 6 月柱状、年度分布
- **预算**：总额 / 餐饮 / 购物，按月固定日或按周重置
- **定期扣款**：按每月固定日期自动生成账单，可撤销
- **外观**：浅色 / 深色 / 跟随系统；两套应用图标（墨绿满未满 / 米白方孔钱）可切换
- **系统**：应用内检查更新 → 下载 → SHA-256 校验 → 调起安装；更新源可自定义；存储占用统计与清理

本地 SQLite，8 张表，含版本迁移框架。预置 5 个账户、9 个支出一级分类（含 48 个二级）、8 个收入分类。

## 本地运行

```powershell
# 1. 生成 android 平台目录（图标、权限、图标切换都在这个脚本里）
powershell -ExecutionPolicy Bypass -File scripts\init_android.ps1

# 2. 拉依赖并运行
flutter pub get
flutter run
```

## 发版

```powershell
powershell -ExecutionPolicy Bypass -File scripts\release.ps1 -Yes -Notes "这次改了什么"
```

脚本会自动构建、校验版本号、建 GitHub Release、上传 APK、更新 `version.json` 并推送。
发版前记得同步改 `pubspec.yaml` 与 `lib/core/version.dart` 的版本号。

## 云端构建

推送到 `main` 后 GitHub Actions 自动跑一遍 debug 构建（只用于验证能编译，不出正式包）。
